# Data Science Notes

Personal hand-written notes from a Data Science course series, condensed and organised into digital format for revision and future reference.


## Topics Covered

**Course 1 — Introduction to Data Science**
- Foundations of Data Science (what it is, the 5-step process, key terms, file formats)
- Cloud Computing for Data Science (deployment & service models)
- Big Data & Data Mining (5 V's of Big Data)
- AI, Generative AI & Data Science
- Applications & Careers in Data Science (case studies: Uber, streaming, healthcare)
- Data Literacy — types & sources of data, APIs, web scraping, RSS, data streams
- Metadata & Metadata Management
- Data Collection & Organization — relational vs non-relational databases
- NoSQL Databases
- Data Warehouses, Marts, Lakes & Pipelines (ETL)

**Course 2 — Tools for Data Science**
- Data Science tool categories & landscape
- Open source tools (data management, ETL/ELT, visualization, model deployment)
- Code & data asset management, dev/execution environments
- Commercial & cloud-based tools
- Python, R & SQL
- Libraries, APIs, datasets & ML models
- Jupyter Notebook & JupyterLab
- Git & GitHub — version control basics, branching, pull requests

**Course 3 — Data Science Methodology**
- What is methodology & why it matters
- The 10-stage Data Science Methodology:
  1. Business Understanding
  2. Analytic Approach
  3. Data Requirements
  4. Data Collection
  5. Data Understanding
  6. Data Preparation
  7. Modeling
  8. Evaluation
  9. Deployment
  10. Feedback
- CRISP-DM framework

**Course 4 — Python Programming**
- Introduction to Python, language vs framework vs library vs product
- Python architecture, execution model, installation
- Imports, namespaces, scope; compile-time vs run-time errors
- Data types, type casting, expressions, operators
- Strings, mutability & object references
- Data structures: tuples, lists, dictionaries, sets
- Conditions, branching & loops
- Functions, exception handling, OOP (objects & classes)
- File handling
- Introduction to Pandas
- Introduction to NumPy — 1D & 2D arrays, broadcasting


## Purpose

These notes are maintained for a quick-reference guide to core Data Science concepts, tools, methodology, and Python fundamentals.
